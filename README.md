# CV Online – Rendy Novian Wijaksono

Website CV/portofolio responsif untuk Rendy Novian Wijaksono, mahasiswa Teknik Informatika
Universitas Muhammadiyah Malang.

**Demo:** https://github.com/Rennn77/cv-rendy--1-

## Teknologi
| Bahasa | Dipakai untuk |
|---|---|
| HTML | Struktur halaman semantik |
| CSS | Layout grid, responsif, tema terang/gelap |
| JavaScript | Ganti tema, kalkulator IPK, validasi formulir, salin email |
| Python | Kalkulator IPK versi terminal + unit test |

## Struktur project
```
├── index.html
├── style.css
├── script.js
├── foto.jpg
├── python/
│   ├── kalkulator_ipk.py
│   └── test_kalkulator_ipk.py
├── commit-bertahap.sh
├── .gitignore
└── README.md
```

## Menjalankan
- **Website:** buka `index.html` di browser.
- **Program Python:** `cd python && python kalkulator_ipk.py`
- **Unit test:** `cd python && python -m unittest`

## Fitur
- Tampilan responsif (HP dan desktop)
- Tema terang/gelap (tersimpan di browser)
- Kalkulator IPK interaktif
- Formulir kontak dengan validasi
